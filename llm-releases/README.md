# 大模型发布追踪

按时间记录主流大模型的发布：谁发布了什么、规格与价格、是否开源、在哪里可用，并附一句话简介和可核验的来源。

> 这里只记“发生了什么”，不做排名。基准分数大多来自厂商自报，引用时请注明出处。

## 记录规范

### 收录范围

- **收录**：通用大语言模型（含多模态 LLM）的新模型、重要版本更新、开源权重发布。
- **暂不收录**：纯图像/视频/语音生成模型、产品功能更新、未经厂商确认的传闻。
- 同一模型的“预览 → 正式版 → 开源权重”合并为一条，在条目内按时间注明。

### 来源可信度标记

每条记录在“来源”一栏标注可信度：

| 标记 | 含义 |
| --- | --- |
| 🟢 官方 | 厂商官网、官方博客、API 文档 / 更新日志、官方 Hugging Face 仓库 |
| 🔵 独立评测 | 第三方用公开方法实测的榜单与价格页（如 Artificial Analysis、LMArena、OpenRouter） |
| 🟡 媒体 | 主流媒体或厂商官方渠道转载的报道（如 Bloomberg、腾讯新闻） |
| 🟠 第三方 | 发布追踪站、博客、维基；数字与日期可能有出入，需再核实 |

日期以**首次公开可用**为准；预览、正式版、开源日期不同时分别写出。

### 条目模板

```markdown
### 模型名（厂商）

- **日期**：YYYY-MM-DD（预览 / 正式 / 权重）
- **类型**：闭源 API / 开源权重（许可证）
- **规格**：总参数 / 激活参数 / 上下文长度 / 模态
- **价格**：输入 $x / 输出 $y（每百万 token）
- **可用渠道**：……
- **简介**：一到三句话，说明它的定位和与上一代相比的关键变化。
- **来源**：🟢 [官方公告](链接)
```

## 更新流程

1. 先查厂商官方渠道；只有第三方来源时标 🟠，并在条目里写明“待核实”。
2. 新条目加到对应年份文件的“速览表”和“详细条目”两处，都按月份分组、按日期先后排列；同一模型的多个阶段放在最早日期所在的月份。
3. 有状态变化（如权重开源、API 开放）时更新原条目，不新增重复条目。
4. 每次更新后修改本页“更新至”日期。
